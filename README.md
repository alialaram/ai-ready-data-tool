# 🚀 AI-Ready Data Tool

> أداة سطر أوامر (CLI) سريعة وخفيفة لتجهيز ملفات CSV الخام لمرحلة النمذجة وهندسة البيانات: توحيد أسماء الأعمدة، معالجة القيم المفقودة، وحذف التكرارات.

## 📌 نظرة عامة

هذا المستودع يمثل حجر الأساس لمسار **Git & GitHub** العملي، حيث يعكس سيناريو واقعي لفرق هندسة البيانات وتطوير نماذج الذكاء الاصطناعي. تم تصميم الأداة بحيث تعتمد على **مكتبة بايثون القياسية فقط** دون أي تبعيات خارجية للتشغيل الفعلي، مما يسهل تشغيلها في أي بيئة خالية من التثبيتات المعقدة.

---

## ⚙️ المتطلبات الأساسية

* **Python 3.9** أو أحدث.
* **`pytest`** (مطلوب فقط لتشغيل وحدة الاختبارات).

---

## 🚀 دليل البدء السريع

قم بتشغيل الأداة عبر سطر الأوامر بالشكل التالي:

```bash
# التشغيل باستخدام الإعدادات الافتراضية من ملف config.yaml
python clean.py

# تجاوز إعداد معين لمرة واحدة (مثال: تغيير استراتيجية معالجة القيم المفقودة)
python clean.py --strategy median

# تشغيل الاختبارات البرمجية للتأكد من سلامة النظام
python -m pytest -v
